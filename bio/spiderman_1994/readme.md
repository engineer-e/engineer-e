| --- | --- |

| **ஷ** | *sha* (எ.கா: விஷயம், ஷண்முகம்) |
| **ஜ** | *ja* (எ.கா: ராஜா, ஜன்னல்) |

| **க்ஷ** | *ksha* (`க்` + `ஷ` + `அ` என்ற கூட்டு எழுத்து; எ.கா: க்ஷணம்) |
| **ஶ்ரீ** | *shree* (மங்களகரமான தொடக்கமாகப் பயன்படுத்தப்படும் கூட்டுக் குறியீடு) |
| **ஶ** | *sha* (பழைய கிரந்த *ஶ* எழுத்து; நவீன தமிழில் **ஷ** அதிகம் புழக்கத்தில் உள்ளது) |
